## 🎮 Project Overview

Neon Synth Snake is a modern browser-based arcade game inspired by the legendary Snake game. The project reimagines the classic gameplay experience with a futuristic **Synthwave** and **Neon Cyberpunk** aesthetic, featuring glowing visuals, smooth animations, and responsive controls.

The game demonstrates frontend development skills, functional programming principles, state management techniques, and interactive game design using ClojureScript and re-frame.

---

## 🎯 Project Objective

The primary goal of this project is to create an engaging and visually appealing version of the classic Snake game while exploring modern frontend architecture and functional programming concepts.

The project focuses on:

* Interactive game development
* Functional programming practices
* State management using re-frame
* Responsive browser-based gameplay
* Modern UI/UX design principles
